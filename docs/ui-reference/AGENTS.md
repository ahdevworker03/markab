# UI Reference

This folder contains approved Replit UI references for Milestone 5.5.

## Purpose

These files are visual and structural references only.

Production implementation must happen inside the real frontend app, not by copying this project directly.

## Rules

- Do not copy Replit code directly into `apps/web`.
- Do not use Replit mock data as product data.
- Do not import Replit routes, app bootstrap, package setup, backend code, scripts, or generated files.
- Use screenshots as the visual source of truth.
- Use Replit frontend code only to understand component structure, spacing, responsive layout, badge styles, card patterns, table patterns, form patterns, and typography.
- Preserve existing app routing, API hooks, authentication, business logic, generated clients, and tests.

## Reference folders

- `replit-approved-screenshots/` — approved visual screenshots.
- `replit-approved-code/frontend-reference/` — frontend-only Replit reference project.
